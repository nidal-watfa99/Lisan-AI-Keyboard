# لسان: لوحة مفاتيح ذكية متعددة اللغات

لسان لوحة مفاتيح نظامية لأندرويد، مع تطبيق إعدادات يدعم العربية والإنجليزية. الشيفرة Kotlin والواجهة الداخلية Jetpack Compose، أما لوحة الكتابة نفسها فتستخدم `InputMethodService`. هذه نسخة اختبار `0.2.0` وليست إصدار متجر. راجع [حالة الميزات](docs/FEATURES.md) و[تقرير الاختبارات](docs/QA.md) قبل توزيعها.

## تثبيت لوحة المفاتيح وتفعيلها

1. افتح ملف `Lisan_AI_Keyboard_0.2.0_Debug.apk` المرفق منفصلاً على جهاز بنظام أندرويد 8.0 أو أحدث. إذا طلب أندرويد السماح بالتثبيت من مدير الملفات أو المتصفح، فعّله لهذا المصدر مؤقتاً وأوقفه بعد التثبيت.
2. افتح «لسان»، ثم «اللغات والتخطيطات». العربية والإنجليزية مفعّلتان مبدئياً، والتخطيطات الفرنسية والألمانية والهولندية والتركية مضمّنة أيضاً. اختر لغتك الافتراضية. لا يتطلب تفعيل تخطيط الكتابة أي تنزيل.
3. اضغط «التفعيل في أندرويد» وفعّل لسان في إعدادات النظام. ارجع إلى التطبيق واضغط «اختيار لوحة المفاتيح»، ثم اختر لسان. لا يستطيع التطبيق تفعيل نفسه نيابةً عن المستخدم.
4. جرّب حقل النص الحقيقي في الصفحة الرئيسية ثم جرّب من تطبيق آخر. زر اللغة يبدّل التخطيط، والضغط المطول يتيح اختيار تخطيط أو فتح محدِّد لوحات النظام. الضغط المطوّل على «الحذف» يحذف كلمة، وعلى «إدخال» يخفي اللوحة.
5. افتح «السمات»، واضغط أي سمة لتجربتها على لوحة تفاعلية. اضغط «تطبيق» لتفعيلها في لوحة النظام. يمكنك تغيير الأحجام والخط واللون من الإعدادات.

## الصوت والترجمة

- **الصوت:** في «الصوت والميكروفون»، اختر اللغة ونزّل أو استورد [نموذج Whisper متعدد اللغات](docs/ENGINES.md) (32.2 ميغابايت). يفضّل الوضع المحلي التلقائي Whisper بعد تثبيته، وإلا يستخدم محرك أندرويد المحلي. اضغط الميكروفون لإنهاء العبارة، ثم اضغطه مجدداً لبدء عبارة أخرى. محرك أندرويد الذي قد يستخدم الشبكة اختياري ويتطلب موافقة.
- **الترجمة:** افتراضياً لغة الهدف هي لغة الجهاز إن دعمها ML Kit. اختر المصدر والهدف لجلسة واحدة أو احفظهما كافتراض. ثبّت النماذج من «نماذج الترجمة» أو عند ظهور زر التنزيل. من الكيبورد اختر نص الحقل أو النص المنسوخ أو الإملاء، ثم عدّل المسودة وراجع الناتج واضغط «إدراج». تتيح الشاشة المستقلة تعديل الناتج و[تهيئة خادم HTTPS اختياري](docs/ENGINES.md) يُطلب منك تأكيد الإرسال إليه في كل مرة.
- **الخصوصية:** لا تحتفظ لوحة المفاتيح بتسجيل صوت ولا تسجل ضغطات المفاتيح. بعض المحركات الصوتية التابعة للنظام قد تستخدم الشبكة إذا فعّلها المستخدم. راجع [سياسة الخصوصية](PRIVACY.md).

تعمل الترجمة الآلية بتقنية «ترجمة Google» عبر ML Kit المحلي. راجع [إرشادات استخدام الترجمة](https://developers.google.com/ml-kit/language/translation/translation-terms) و[وثائق ترجمة Google](https://docs.cloud.google.com/translate/docs).

## فتح المشروع وبناء APK

فكّ ZIP وافتح مجلد `Lisan_AI_Keyboard` في Android Studio. استخدم JDK 17 وثبّت Android SDK Platform 36 وBuild-Tools 35.0.0 وPlatform Tools وNDK `28.2.13676358` وCMake `3.22.1`. عيّن `ANDROID_HOME` عند البناء من الطرفية. يحتاج أول بناء إلى الاتصال بمستودعات Gradle وMaven الرسمية. يتضمن الأرشيف مصدر محرّك Whisper، لا أدوات SDK أو ملفات النماذج الكبيرة.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

في Windows استخدم `gradlew.bat`. تجد الحزمة الناتجة في `app/build/outputs/apk/debug/app-debug.apk`. يحتاج الأمر الثاني إلى هاتف موثّق عبر ADB أو محاكي يعمل. لبناء المتجر، راجع مستوى Android المستهدف ومتطلبات النشر آنذاك ووقّع إصدارك بمفتاح خارج المستودع.
